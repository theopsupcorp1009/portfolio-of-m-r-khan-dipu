## 🚀 Installation & Local Execution

### 1. Prerequisites
- Node.js 18.17+ or 20+
- npm (v9+) or pnpm

### 2. Install Dependencies
```bash
npm install
```

### 3. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Production Build & Execution
```bash
npm run build
npm start
```
