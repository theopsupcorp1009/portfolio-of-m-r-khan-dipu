## 🚀 Overview

**M R Khan Dipu — Full-Stack Developer Portfolio** is a responsive, multipage web application built to present my technical skills, software projects, academic background, professional experience, and research in a single, cohesive experience.

Designed around an immersive **cinematic superhero aesthetic**, the portfolio combines a deep-black interface, neon-red energy effects, futuristic HUD elements, atmospheric rain, and interactive identity-reveal animation with a structured, professional presentation of academic and career information.

The experience is more than a static portfolio. Visitors can explore individual project pages, interact with skills categories, access my résumé, review research information, and navigate directly to contact channels.

**[https://portfolio-of-m-r-khan-dipu.vercel.app/](https://portfolio-of-m-r-khan-dipu.vercel.app/)**

**Deployment platform:** Vercel

## 🛠️ Technology Stack

The portfolio uses a modern React and Next.js stack with a utility-first styling approach.

| Category | Technology |
|---|---|
| Framework | Next.js 16 |
| Routing | Next.js App Router |
| Language | TypeScript |
| UI Library | React 19 |
| Styling | Tailwind CSS v4 |
| Icons | Lucide React and custom SVG graphics |
| Animation | CSS keyframes and motion effects |
| Image Optimization | Next.js Image |
| Deployment | Vercel |
| Runtime | Node.js |

### Why this stack?

- **Next.js App Router:** Organizes the application into dedicated pages and dynamic project routes.
- **TypeScript:** Provides static typing for improved maintainability and developer confidence.
- **React 19:** Supports reusable components and interactive interface behavior.
- **Tailwind CSS v4:** Enables consistent, responsive styling and rapid interface development.
- **CSS animations:** Power the cinematic identity reveal and atmospheric visual effects.
- **Vercel:** Hosts the deployed portfolio.

## ⚙️ Installation & Local Development

### Prerequisites

Install the following before running the project:

- Node.js compatible with your installed Next.js version.
- npm or pnpm.
- Git, if cloning the repository.

For Next.js 16, use a supported Node.js version. Node.js 20.9 or later is the appropriate minimum baseline for this project.

### 1. Clone the Repository

```bash
git clone https://github.com/theopsupcorp1009/portfolio-of-m-r-khan-dipu
```

Move into the project directory:

```bash
cd portfolio-of-m-r-khan-dipu
```

Replace the placeholders with your actual repository URL and folder name.

### 2. Install Dependencies

Using npm:

```bash
npm install
```

Alternatively, if the project uses pnpm:

```bash
pnpm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Open the application in your browser:

**http://localhost:3000**

### 4. Create a Production Build

```bash
npm run build
```

### 5. Run the Production Server

After the build completes successfully:

```bash
npm start
```

The application should then be available at the local address shown by Next.js.

Accuracy is an essential part of this portfolio.

- **Verified background:** Academic qualifications and professional responsibilities should match the verified CV and supporting records.

- **No fabricated metrics:** Skill percentages, citation counts, and publication identifiers are not invented.
- **Accurate publication details:** Conference papers, thesis titles, and publication information should be presented only when supported by reliable records.
- **Clear project descriptions:** Implemented features are distinguished from proposed future improvements.

This approach keeps the portfolio visually expressive without compromising academic or professional credibility.
